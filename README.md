# Toumadher Barhoumi Academic Website

Personal academic website of **Toumadher Barhoumi**, Ph.D., hosted using GitHub Pages.

The website presents my research in electrified propulsion systems, hybrid and extended-range electric vehicle powertrains, system modeling, optimization, energy management, and control.

## Website

Visit the website at:

https://toumadherb.github.io

## Main Files

- `index.html` — Main single-page academic website
- `assets/styles.css` — Website styling and responsive layout
- `assets/site.js` — Publications, patents, search functions, tabs, and background animation
- `assets/profile.jpg` — Profile photo
- `assets/favicon.svg` — Website icon
- `robots.txt` — Search-engine crawling instructions
- `sitemap.xml` — Website structure for search engines
- `404.html` — Fallback page for GitHub Pages

## Research Areas

My research focuses on:

- Electrified propulsion system design and optimization
- Hybrid electric vehicles (HEVs), plug-in hybrid electric vehicles (PHEVs), and extended-range electric vehicles (EREVs)
- Powertrain architecture design and design-space exploration
- Energy management and optimal control
- Multi-mode transmissions and mode-shift control
- Vehicle modeling and simulation
- Hardware-in-the-Loop Simulation (HILS)
- Connected and intelligent energy-efficient mobility

- `fullPublications`

- `patents`

## Updating the Website

After editing a file on GitHub:

1. Make the required changes.
2. Click **Commit changes**.
3. GitHub Pages will automatically update the website.

No additional build step is required.
